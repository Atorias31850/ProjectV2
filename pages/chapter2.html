ดาวน์โหลดและติดตั้ง Git

ไปที่เว็บไซต์ git-scm.com แล้วดาวน์โหลดเวอร์ชันที่เหมาะกับระบบปฏิบัติการของคุณ

🪟
Windows
ดาวน์โหลด .exe installer จาก git-scm.com แล้วติดตั้งแบบ Next → Next → Finish
🍎
macOS
ใช้ Homebrew: brew install git หรือติดตั้งผ่าน Xcode Command Line Tools
🐧
Linux (Ubuntu)
ใช้ apt: sudo apt install git

ขั้นตอนติดตั้ง Git บน Windows

  1. ดาวน์โหลด Git for Windows
    เข้าเว็บ git-scm.com/download/win แล้วดาวน์โหลดไฟล์ติดตั้งสำหรับ Windows
  2. เปิดไฟล์ติดตั้ง
    กด Next ตามค่าเริ่มต้นได้เลย แนะนำให้เลือกตัวเลือก Git Bash และ Git from the command line เพื่อใช้คำสั่ง Git ได้จาก Terminal
  3. ติดตั้งเสร็จแล้วเปิด Git Bash
    ค้นหา Git Bash จาก Start Menu แล้วเปิดขึ้นมาเพื่อทดสอบคำสั่ง Git
  4. ตรวจสอบเวอร์ชัน
    พิมพ์ git --version ถ้ามีเลขเวอร์ชันแสดงว่าใช้งานได้แล้ว

ขั้นตอนติดตั้ง Git บน macOS

  1. เปิด Terminal
    เปิดแอป Terminal จาก Launchpad หรือ Spotlight Search
  2. ติดตั้งผ่าน Xcode Command Line Tools
    พิมพ์ xcode-select --install แล้วทำตามหน้าต่างติดตั้ง
  3. หรือใช้ Homebrew
    ถ้ามี Homebrew แล้ว สามารถติดตั้งด้วย brew install git
  4. ตรวจสอบเวอร์ชัน
    พิมพ์ git --version เพื่อยืนยันว่าติดตั้งสำเร็จ

ขั้นตอนติดตั้ง Git บน Linux

  1. เปิด Terminal
    ใช้ Terminal ของ Linux distribution ที่ใช้งานอยู่ เช่น Ubuntu, Debian, Fedora หรือ Arch
  2. ติดตั้งด้วย Package Manager
    Ubuntu/Debian ใช้ sudo apt update แล้วตามด้วย sudo apt install git
  3. ตัวอย่างคำสั่งสำหรับระบบอื่น
    Fedora ใช้ sudo dnf install git และ Arch ใช้ sudo pacman -S git
  4. ตรวจสอบเวอร์ชัน
    พิมพ์ git --version ถ้าเห็นเลขเวอร์ชันแปลว่า Git พร้อมใช้งาน

ตรวจสอบการติดตั้ง

bash – ตรวจสอบเวอร์ชัน Git
git --version # ผลลัพธ์ที่ควรได้ (เวอร์ชันอาจแตกต่างกัน) git version 2.44.0

Config ข้อมูลผู้ใช้ (ต้องทำก่อนใช้ครั้งแรก)

Git จะใช้ข้อมูลนี้เพื่อบันทึกว่าใครเป็นคนทำ Commit ต้องตั้งค่าครั้งเดียวต่อเครื่อง

bash – ตั้งค่าชื่อและอีเมล
# ตั้งชื่อผู้ใช้ (ใช้ชื่อจริงหรือชื่อ GitHub ก็ได้) git config --global user.name "ชื่อของคุณ" # ตั้งอีเมล (ใช้อีเมลเดียวกับ GitHub) git config --global user.email "email@example.com" # ตรวจสอบการตั้งค่าทั้งหมด git config --list

สร้างบัญชี GitHub

  1. ไปที่ github.com
    เปิดเบราว์เซอร์แล้วไปที่ github.com คลิกปุ่ม "Sign up"
  2. กรอกข้อมูล
    ใส่ Email, Password และ Username ที่ต้องการ ชื่อ Username จะใช้เป็น URL โปรไฟล์ของคุณ
  3. ยืนยันอีเมล
    GitHub จะส่ง code ไปที่อีเมล กรอก code เพื่อยืนยันตัวตน
  4. ตั้งค่าโปรไฟล์
    เพิ่มรูปโปรไฟล์ ชื่อ และ bio เพื่อให้โปรไฟล์ดูน่าเชื่อถือ
💡 เคล็ดลับ
ใช้อีเมลเดียวกันใน Git config และ GitHub account เพื่อให้ Commit ของคุณแสดงรูปโปรไฟล์ถูกต้อง

เชื่อม Git ในเครื่องกับ GitHub

หลังจากติดตั้ง Git และสมัคร GitHub แล้ว ต้องเชื่อมโปรเจกต์ในเครื่องกับ repository บน GitHub เพื่อให้สามารถ push และ pull โค้ดได้

  1. สร้าง Repository บน GitHub
    เข้า GitHub แล้วกด New repository ตั้งชื่อโปรเจกต์ เลือก Public หรือ Private จากนั้นกด Create repository
  2. เริ่ม Git ในโฟลเดอร์โปรเจกต์
    เปิด Terminal ในโฟลเดอร์งาน แล้วใช้คำสั่ง git init
  3. เพิ่ม Remote Origin
    คัดลอก URL ของ repo จาก GitHub แล้วใช้คำสั่ง git remote add origin URL_REPO
  4. Push ขึ้น GitHub ครั้งแรก
    ใช้คำสั่ง git push -u origin main เพื่อส่งโค้ดขึ้น GitHub และตั้งค่าให้ branch main จำ remote ไว้
bash – ตัวอย่างการเชื่อมโปรเจกต์กับ GitHub
git init git add . git commit -m "Initial commit" git branch -M main git remote add origin https://github.com/username/project-name.git git push -u origin main
